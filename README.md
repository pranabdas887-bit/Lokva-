# LOKVA Demo Website

**LOKVA — Local Roots. Wider Reach.** is an idea-stage concept for a regional-first marketplace for local products from Assam.

## GitHub Pages deployment

1. Create or open a GitHub repository.
2. Upload `index.html`, `README.md`, and `.nojekyll` to the repository's **root** folder.
3. Commit the files to the default branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select your default branch (for example, `main`) and folder `/ (root)`, then save.
7. After GitHub Pages finishes publishing, open the URL shown in Settings → Pages.

## Demo features

- Responsive concept homepage
- Sample product catalogue with illustrative listings and prices
- Search, category filters, location filters and sorting
- Demo shopping bag
- Seller-interest form preview

## Important limitations

This is a **front-end concept prototype only**. It does not include a backend, persistent data storage, real seller accounts, order processing, payment integration, or delivery integration. The form does not send or save submitted information. Product names, seller names, and prices are illustrative examples.

Describe LOKVA honestly as an **idea-stage project with an interactive front-end concept prototype**, not as a launched marketplace.
